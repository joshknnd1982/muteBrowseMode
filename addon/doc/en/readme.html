Mute Browse Mode

NVDA normally announces a browse mode document every time one is entered: the document name, the word "document", and the first line of the buffer. That happens when a web page finishes loading in Chrome, when you switch to a browser window, and when you open a message in any version of Microsoft Outlook.

This add-on adds a Mute browse mode combo box to NVDA's Speech settings (NVDA menu, Preferences, Settings, Speech) with three choices.

Silence all browsing

NVDA stays silent while a document is loading and when it has finished loading. "Loading document..." is not spoken either. Reading the page yourself with the arrow keys, quick navigation keys and everything else works exactly as usual.

Play tones

Speech is silenced the same way, but three quick ascending tones are played when the document is ready, so you still know when you can start reading.

Normal

NVDA behaves exactly as if the add-on were not installed. This is the default.

Outlook and Chromium browsers

In Microsoft Outlook and in every Chromium based browser, the two choices above go further than they do elsewhere. As well as the document announcement, NVDA no longer speaks:

  • window titles, so switching to Outlook no longer reads the title of the message list window, and opening a message no longer reads the title of the message window;
  • document titles, so a browser tab no longer announces the page title;
  • toasts and notification balloons, such as a browser's download and pop-up messages;
  • live region "flash" messages, which is how web pages announce things like "Message sent" or "Your changes were saved".

Every Chromium based browser is covered, including Chrome, Edge, Brave, Opera, Vivaldi and forks of them, because the add-on recognises them by the windows Chromium creates rather than by a list of program names. The new Outlook for Windows is recognised the same way, as it is built on the same engine.

You can still ask for any of this at any time. NVDA+t reads the title, and NVDA+tab reads the focus, exactly as usual: only the announcements NVDA makes on its own initiative are dropped.

Notes

  • Pressing any key immediately restores normal speech, so the add-on can never leave NVDA quiet when you are trying to work.
  • Braille is untouched. The document, the current line, alerts and flash messages are all still brailled, including the ones that are no longer spoken.
  • Moving around inside a document with tab, the arrow keys and the quick navigation keys always speaks. Only arriving in a document from outside it is silenced.
  • Say all is never silenced. If you use Browse Mode settings, "Automatically say all on page load", NVDA will still read the page to you after it loads. Turn that setting off if you want the silence.
  • If Browse Mode settings, "Audio indication of focus and browse modes" is on, you will still hear that short sound when a document is entered, because it is a sound rather than speech. Turn it off and NVDA speaks "browse mode" instead, which this add-on does silence.
  • A command to cycle between the three choices is available in the Input Gestures dialog under "Mute Browse Mode". It has no gesture assigned by default.

Changes

1.1

  • Fixed the first line of an Outlook message still being read when the message was opened. NVDA reads that line from a focus event rather than from the document load, so silencing the load never reached it.
  • Window titles and document titles are no longer spoken in Outlook or in Chromium based browsers.
  • Browser flash alerts, live region messages and toasts are now silenced too.
  • The tones now also play when an Outlook message is opened.
